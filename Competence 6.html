Sokoban

Contexte : Dans le projet nous devions refaire le casse-tête Sokoban
Le but du jeu est que le joueur arrive a mettre toutes les caisses
aux emplacements marqués.
Le cahier de charge etait :
-Pas d'interface graphique nous allons utiliser le terminale de commande afin d'afficher le jeu
-Tout le jeu devait etre codé en C
-Le jeu devait pouvoir chargé et sauvegardé les parties sur des fichiers externes
-Le jeu devait afficher diverse informations mise a jour en direct tel le nombre de déplacement

J'ai réaliser le projet en 3 étapes:
-Reflexion sur le code en pseudo code. Afin de trouver les potentiels problemes que j'aurais en codant tout en respectant le cahier des charge et rendre le code modulable afin de pouvoir repondre a tout changement de consigne en plein dévellopement.

-Le dévellopement en soit qui consistait a transposé le pseudo code en C et ne pas oublié les bonne nomenclature et des commentaires afin que mon code soit clair pout tout le monde

-Le débogage qui a était la partie la plus longue car j'ai eu un "bug fantôme" un bug qui n'etait jamais le meme quand je compilais mon code
Malgré tout le temps que j'ai passé a le fixé et je n'ai pas réussi a le corrigé entièrement

Résultat: Malgré tout le temps que j'ai passé a corrigé le bug il est rester et a empecher certaines execution
depuis J'ai fait tout le temps des test unitaire afin de tester la moindre fonctionalité
